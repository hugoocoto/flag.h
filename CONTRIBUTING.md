Contributions Welcome
=====================

Pull Requests and Issues are both welcome.


### Responsiveness

General priority order is:

* Crashes
* Security converns
* Bugs
* Warnings
* Enhancements (new features, performance improvement, etc)

### Pull requests

* Make sure you're using a special branch just for this pull request. 
* Make sure it compiles using c99.
* Do NOT update the version number in the VERSION file. 
* Do add your name to the list of contributors.
